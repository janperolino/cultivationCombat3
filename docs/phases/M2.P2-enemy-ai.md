- `src/content.ts` adds `ruin-skirmisher` and `skirmish-arena`. The playable encounter has three 400hp realm-1 enemies with perception 150m, attack range 42m, flight speed 12m/s, crescent windup 1.1s and recovery 2.4s. Validated combat fields and cross-references remain host-owned and immutable. The content/replication bound is six enemies plus reserved players 0/1. A spawn count creates a four-metre line formation; total counts and formation arena edges are checked before construction.
- `src/enemy-ai.ts` holds per-enemy mutable decisions outside definitions. Targets are nearest living hostile reserved player actors in 3D range, ties broken by ID. Proximity sensing does not require visibility; attack release positions require a sampled clear line. Each enemy independently approaches with shared swept collision, altitude pursuit, rise-only cover lookahead and a stable perpendicular fallback when congested. A deterministic regression crosses a tree wall backed by a ridge and damages an airborne target.
- Each attack warns before release; the actor freezes and the aim coordinates stay committed during windup. Default crescents use the existing vertical slope and collision/damage behavior. Cooldown/qi remain authoritative; recovery separates attempts. Owner death, target death, leaving perception or becoming allied cancels the pending warning without resource consumption. Existing bolt guidance would still apply if a host authors bolt behavior; only crescent behavior is selected by the new encounter.
- `World` now constructs a bounded enemy roster, stable numeric IDs 2–7 and definition identities, with no runtime spawn/reset API. Solo default still uses its original rival AI; the stationary sentinel encounter stays unchanged. `npm run encounter` builds and runs skirmish at port 5174; `npm run spike` keeps the M1 stationary baseline. The new scene waits for first Join to avoid defeat before anyone enters, then runs continuously even through idle/disconnect/Leave. Both reserved player actors remain vulnerable whether occupied or not; no policy change or healing on join/recovery.
- Protocol **4** carries full bounded actor arrays, enemy IDs and up to six warnings through live frames and atomic paged snapshots. Frame validation rejects out-of-range/duplicate actor IDs, invalid identities/cooldowns, invalid or duplicate warning owners/targets, unsupported techniques, bad durations and nonfinite warning coordinates. Packet/cell limits remain 64KiB/1024. Terrain schema stays v2. Restart older hosts and reload older clients; protocol 3 is intentionally incompatible.
- `src/spike-client.ts` displays generic enemy identities/colors beyond ID 2 and dashed amber crescent corridors with committed aim/altitude/countdown. These are conservative direction/altitude cues, not exact damage-volume or terrain-interception previews. `tools.mjs` emits and rewrites `enemy-ai.js`; the host serves it and content.js. Original-study rendering remains separate for P5a.
