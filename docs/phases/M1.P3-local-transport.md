## Brief

Deliver a loopback Node host and a browser sparring harness where two real tabs receive separate authority assignments, move/fly/dodge/cast through M1.P2 validation, and observe the same authoritative actors, attacks, damage, and terrain. Read STATUS.md, WORKFLOW.md, IMPLEMENTATION_PLAN.md, M1.P2 handoff, session-authority.ts, sim.ts, main.ts, and tools.mjs. No new repository instructions found.

Decision: use built-in Node HTTP plus browser fetch: command POSTs at up to 30 Hz and observation GETs at 10 Hz. The authority runs fixed 60 Hz steps independently. No runtime dependency or hosted service, no relay/account cost; local CPU/network only. This prioritizes a small inspectable local connection over internet latency suitability. WebSocket remains a future candidate if polling overhead/latency is unacceptable; WebRTC would introduce signaling/peer-host concerns unnecessary here. No production transport/hosting commitment.

API references: [Node HTTP](https://nodejs.org/api/http.html), [browser Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API). Uses installed Node 24's existing TypeScript stripping support, with the same browser build tooling as the combat study.

Rules: bind only 127.0.0.1; host assigns first free of two actor seats. An unpredictable per-tab bearer token identifies each connection independently, including two tabs in one browser. A random server session ID and authority generations reject previous-host packets. This is possession-based local connection identity, not account authentication. No CORS; validate Host/Origin and reject cross-site requests. Bound JSON bodies, request intake, connection seats, observation size, and server request timeouts. Five seconds without a valid heartbeat frees the seat; explicit Leave frees it immediately. Authority stale input still expires after 250 ms. No seamless rejoin or host recovery claim.

Observation: each response is a current full display frame with tick, actors, visible attacks, terrain revision, and all changed cells relative to a deterministic initial World. Each client rebuilds changes from that baseline and discards older ticks. No replay, prediction, interpolation, resume protocol, delta acknowledgment, or persistence. This is deliberately temporary observation plumbing; M1.P4 must replace/review it for bounded ordered replication. Polling may miss brief effects and has visible latency.

Scene: existing two actors remain damageable opponents; label it a sparring transport test. No ally/team policy or production art change. Clients never step a local simulation or grant combat state. Existing solo page/controls/local saves remain separate.

Acceptance: automated real-HTTP tests for assignment/full session, connection identity, rejected malformed/oversized/unauthorized/cross-origin/stale-session input, bounded ingress, fixed ticking, shared movement/casts/damage/terrain observation, late observation, and leave/lease expiry. Two actual browser tabs must join and exercise controls against one host, with observations/console errors checked. Run full tests/type check/build, document results and limits, update status/checklist, stop before M1.P4.

Adapter details: JSON command body limit 2048 bytes; response budget 4 MiB; two seats; 100 API requests/second per connection and 200/second across API traffic; 16 TCP connections; 3-second request/socket timeouts. Tokens remain per-tab in memory and are never put into URLs or browser storage. Static file paths are allowlisted. Current frames cache by authority tick and include all mutation-stamped cells relative to a fresh procedural World. Up to five fixed steps catch up per scheduler callback; excessive suspended-process time is dropped and reported, rather than simulating a large dt. Empty/silent seats remain authority-controlled and cannot become rival AI.

Limitations: local possession tokens are not production account authentication; no internet/LAN service or HTTPS configuration. Current full observations can grow with destroyed terrain and are intentionally bandwidth-heavy; there are no acknowledged deltas, versioned baseline handshake, reliable effect history, or congestion strategy. Client frame ticks reject older observations, but polling is not the M1.P4 ordered replication protocol. Cast/dodge requests can be superseded in M1.P2's latest-input slot; there is no reliable action receipt protocol yet. No prediction/interpolation, persistence, seamless reconnect, host transfer, team/ally rules, or co-op encounter. Browser background throttling can expire a seat, after which the user must Join again.
