## Measured seeded workload

Reproduce with `npm run bench:network`. The checked-in JSON comes from the script, not manually authored estimates. Each profile runs 45 virtual seconds: 20 seconds of two actors reversing movement/climbing in a clear arena, then settling. A full 16,384-cell terrain mutation occurs at 15 seconds. Initial joins are warmed before impairment. Ongoing commands, live observations, and the real acknowledged terrain stream use the shared seeded profile generator; command concurrency matches the browser's six-request cap. The scheduler quantizes to 60 Hz, so effective mean RTT is above the target. Error percentiles use the active 20-second window, not the idle tail. Maximum state age/correction use the whole run.

All profiles reached equal terrain under impairment before the final reliable verification/drain, settled to 0.000 m reported final position error, kept bounded histories, and preserved the authoritative shared clock. Model JSON payload totals were about 2.0–2.8 MB across both clients over 45 seconds; these exclude warm joins, HTTP/TCP headers, and some adapter envelopes and are not a measured socket-bandwidth budget. The clear-arena workload does not measure arbitrary enemy density, campaign content, or subjective action responsiveness. Collision/replay tests cover walls separately.

The results expose real limitations: loss bursts can pause prediction at the conservative 250 ms freshness limit and cause metre-scale corrections when fresh state returns. A full-world paged transfer remains slow under RTT; separate live actor updates avoid freezing that display while terrain catches up. Regression envelopes protect this workload against worsening; they do not certify these values as acceptable gameplay. ## Implementation and scope decisions

- Motion uses existing World climb/autoClearance/locomotion against the last committed replicated terrain and last authoritative other-actor positions. It never calls combat stepping, cast, terrain mutation, or dash onset. Collision/terrain changes and remote motion can cause corrections. Authoritative active dodges are projected, but new dodges and casts wait for the host.
- On a newer live frame, replace local predicted actor state and replay at most 120 retained motion samples after the estimated client-clock capture instant. Midpoint timing assumes approximate symmetry and is not exact reconciliation under asymmetric delay. Receipts retire at most 64 pending command markers; they do not prove every coalesced action executed. Samples outside retained history cause a hard rebase. Freshness is checked in both prediction ticks and browser wall time, including suspended rendering. Recovery snapshots instantiate a fresh predictor.
- Remote interpolation keeps 32 snapshots and delays presentation by 12 authority ticks (200 ms). It interpolates position/height and shortest-path aim, clamps on buffer starvation, and never drives gameplay. Health/qi and attacks remain authoritative observations; only positions are predicted/interpolated. No independent client combat clock or time dilation is introduced.
- Protocol 2 retains the M1.P4 terrain schema, paging, sequence/ack, and resync rules. `GET /api/live` adds same-authenticated-connection live frames with protocol/schema/session identity, monotonic tick/receipt validation, and the same 64 KiB response budget. Live requests refresh leases; command staleness remains independent. A live terrain revision may be newer than committed local terrain; the UI shows both. Initial snapshots still gate input, terrain commits atomically, and live state alone never grants a terrain edit.
- Browser live polling is at up to 10 Hz, terrain fill at up to 40 Hz, input at up to 30 Hz with six concurrent requests; existing host ingress limits remain. Presentation runs per animation frame with cached terrain painting. The network selector adds seeded up/down delay and independently drops application requests/responses at the specified per-direction rate; either-direction loss can fail one transaction. Actual HTTP/TCP remains reliable. Dropped/reordered command states can be superseded and are never replayed as damage grants.
- Discrete action reliability, predicted attacks, visual correction easing, better clock estimation, faster terrain batching, transport selection, and production tuning remain open. This phase measures a useful foundation; it does not claim final combat feel or guaranteed casts. Full reconnect/persistence/host departure remains M1.P6; ally/team policy is unchanged.
