## Recovery contract

`backups/M0.P1-baseline.bundle` contains committed history and all tracked source, tests, browser assets, dependency manifest/lockfile, design documents, art guide, endorsed PNG and prompt, and phase records. It excludes Git local configuration/identity, hooks, reflogs, ignored files, and changes made after the bundled commit. It is a local backup on the same disk, not protection against disk loss.

Ignored artifacts: `node_modules/` is installed generated tooling (recreate with `npm ci`); `dist/` is generated output (recreate with `npm run build`). Logs are disposable. `backups/`, `.recovery-check/`, `.recovery-check-final/`, and `*.bundle` are deliberately excluded to prevent recursive backups. `.env` files are excluded credentials and would need separate secure backup if introduced; none were present at baseline. Browser localStorage saves/settings are outside the workspace and are not captured. No necessary unique project artifact was identified outside tracked files.

Restore from the project directory into a new, nonexistent destination:

```powershell
git bundle verify backups/M0.P1-baseline.bundle
git clone backups/M0.P1-baseline.bundle .recovery-check
Set-Location .recovery-check
npm ci
npm test
npm run check
npm run build
```

The verification directory is disposable and ignored. Keep backups outside Git; refresh with `git bundle create backups/M0.P1-baseline.bundle --all` after future commits, then verify and restore again. Do not overwrite the only known-good backup before verifying its replacement.
